Privacidade nos canais digitais

Esta página explica, em linguagem objetiva, como os canais digitais da Code Solution foram estruturados para coletar apenas as informações necessárias ao atendimento comercial e técnico.

Resumo

O Diagnóstico Digital calcula o resultado no próprio navegador e não envia as respostas. O Codi processa as mensagens necessárias ao atendimento. Quando uma pessoa decide solicitar contato da equipe, os dados informados podem ser registrados no CRM para continuidade do atendimento.

Quais dados podem ser informados

Nos fluxos de contato podem ser solicitados dados como nome, WhatsApp, e-mail, empresa, segmento e uma descrição da necessidade. A pessoa não deve enviar senhas, dados bancários, documentos sigilosos ou outras informações sensíveis que não sejam necessárias para o atendimento.

Para que os dados são usados

As informações fornecidas nos canais de atendimento são utilizadas para responder à solicitação, qualificar a necessidade, organizar o acompanhamento comercial ou técnico e manter o histórico necessário à continuidade da conversa.

Diagnóstico Digital

As respostas da autoavaliação em /diagnostico/ são processadas localmente no navegador. A página não envia as respostas do questionário ao servidor. Se a pessoa escolher continuar pelo WhatsApp, apenas o resultado resumido é colocado na mensagem que ela decide enviar.

Codi e CRM

A conversa com o Codi é processada para gerar respostas. O registro de um lead no CRM só ocorre quando o visitante fornece os dados necessários e confirma o envio para continuidade do atendimento. O CRM é uma ferramenta interna e possui controle de acesso.

Compartilhamento e fornecedores

Os canais podem depender de provedores de infraestrutura, inteligência artificial, hospedagem, comunicação e mensageria necessários à execução do serviço. A Code Solution busca limitar o envio de dados ao necessário para cada função do fluxo.

Segurança

Os painéis internos são protegidos por autenticação e configurados para não serem indexados. Segredos de integração não são armazenados no código do site ou expostos no navegador.

Solicitações relacionadas a dados

Para solicitar informações sobre dados fornecidos à Code Solution, correção de dados cadastrais ou tratar de uma solicitação de privacidade, use o canal de contato da empresa e identifique o assunto como “Privacidade”.
